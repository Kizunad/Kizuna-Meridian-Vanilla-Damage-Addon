# 原版伤害映射附属

本附属在 Minecraft 原版护甲阶段确定身体命中部位，只用覆盖该部位的单件护甲与韧性计算基础减免，乘可配置的耐久曲线系数后应用减免比例上限（默认 60%），随后保留原版抗性、保护附魔与吸收生命结算，再提交 Framework 身体 HP。上限和曲线默认值为可调占位参数。无敌帧保留。原版死亡确认身体死亡，伤害使身体判死时同步实体死亡；死亡后保留局部伤势，复活规则另定。

- [构建与宿主接入](Integration.md)
- [伤害、命中偏好与死亡](Damage-Rules.md)

`server/` 提供配置、部位选点、单件护甲公式及 Protobuf 请求编排；`fabric/` 读取 Minecraft 1.20.1 装备并接入伤害与死亡事件。人体内部损伤与死亡阈值仍由 Human 配置，其他生物可提供自己的身体宿主与伤害策略。
