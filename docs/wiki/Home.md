# 原版伤害映射附属

本附属在 Minecraft 原版护甲阶段确定身体命中部位，只用覆盖该部位的单件护甲与韧性计算基础减免，乘可配置的耐久曲线系数后应用减免比例上限（默认 60%），随后保留原版抗性、保护附魔与吸收生命结算，再提交 Framework 身体 HP。上限和曲线默认值为可调占位参数。无敌帧保留。原版死亡确认身体死亡，伤害使身体判死时同步实体死亡；死亡确认保留局部伤势，玩家重生由 Human 显式提交 Framework 复活命令，恢复局部最低 HP、置满肌肉疲劳并扣寿元。类人生物不自动复活。

- [构建与宿主接入](Integration.md)
- [伤害、命中偏好与死亡](Damage-Rules.md)
- [肌肉出力与伤害标签实现验证](Muscle-Validation.md)

`server/` 提供配置、部位选点、单件护甲公式及 Protobuf 请求编排；`fabric/` 读取 Minecraft 1.20.1 装备并接入伤害与死亡事件。人体内部损伤与死亡阈值仍由 Human 配置，其他生物可提供自己的身体宿主与伤害策略。

近战来源由 `#meridian:melee` 标签声明；伤害在护甲前乘攻击者实际出手肌肉的可用力量系数，并向攻击者宿主提交原子做功。数据包还可指定副手、双手及致伤分类，规则与配置见上面的伤害说明。

每次命中按护甲后剂量占命中部位上限的比例换算受击僵直，写入功法库：起手中可打断的功法被打断，僵直期间减速且不能起新式。
